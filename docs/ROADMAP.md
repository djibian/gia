# Roadmap

Gia 0.7.0 is the current product. MCP contract major 2 and the existing security
boundaries remain fixed for the authorized repository-convergence work.
No functional expansion or public-directory publication is authorized.

## Committed unfinished work

- Remove the remaining unused contract/help/output-schema helpers and obsolete
  compatibility declarations, preserving assertions at the active MCP boundary.
- Consolidate the equivalent sequential batch executors and strict widget
  column-map resolution only where net complexity decreases without behavior change.

Implementation is bounded by [AGENTS.md](../AGENTS.md). Remove each entry when
integrated; PRs, commits and CI hold completion history.

## Selection policy

Further work requires explicit user authorization or a reviewed finite addition
here based on concrete product evidence. Advice, upstream breadth and deferred
publication are not an implicit backlog. No useful eligible work means stop.
