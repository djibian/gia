# Roadmap

Gia 0.10.0 is the current product, implementing MCP contract major 2.
Public-directory publication remains inactive.

No functional evolution is currently selected.

New capabilities require concrete important generic evidence, explicit product
authorization, a bounded implementation and justified maintenance cost, as
specified by [AGENTS.md](../AGENTS.md) and
[Product Vision](PRODUCT_VISION.md). The current implementation and its
safety/compatibility limits are documented in
[MCP Contract](MCP-CONTRACT.md), [Security](SECURITY.md) and
[Development](DEVELOPMENT.md).
