# Support — Structured Workspace Builder

Structured Workspace Builder is an independent remote MCP plugin for bounded work with one configured self-hosted Grist Community deployment.

## Get help

Public support requests and bug reports:

https://github.com/djibian/grist-chatgpt/issues

When opening an issue, include:

- what you were trying to do;
- the tool or workflow involved, if known;
- what you expected;
- what happened instead;
- non-sensitive error text that helps reproduce the problem;
- the approximate time of the failure when relevant.

## Do not post secrets or restricted data

Never include any of the following in a public support issue:

- OAuth access, refresh or ID tokens;
- passwords, API keys or Grist service-account credentials;
- MFA/OTP codes or authorization codes;
- payment-card data;
- protected health information;
- government identifiers;
- private Grist record contents that are not necessary to reproduce the issue.

Redact document identifiers, personal data and business content when they are not necessary for diagnosis.

## Security issues

For a suspected security issue, first open a minimal GitHub issue that contains no exploit secrets, credentials or private user data and clearly mark it as a security report. The publisher will coordinate a safer channel if non-public details are required.

## Scope

Support covers the Structured Workspace Builder MCP bridge and its public deployment. Questions about the Grist product itself should use Grist's official documentation and support channels.
